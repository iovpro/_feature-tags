# Rust · `reference`

| Поле            | Значение |
| --------------- | -------- |
| Файлы           | `--include=*.rs`. Исключения: `target/`, `build.rs`-вывод, `*.pb.rs` |
| Комментарий     | `//` — **не** `///` и не `//!`, чтобы тег не попал в rustdoc |
| Тег-группа      | Отдельная `//`-группа перед `///`-doc, атрибутами (`#[…]`) и объявлением, отделённая от них пустой строкой |
| Объявления      | `fn`, метод в `impl`, `struct`/`enum`/`trait` (уровень фичи), `impl Trait for` |
| Ветка           | Хвостовой `// #f:…` на match-arm или `if` |
| Тесты           | `#[test]` / `#[tokio::test]` в `mod tests` и `tests/`; тест — `fn (\w+)` после атрибута; отдельная тег-группа перед test doc/атрибутом |
| Точечный прогон | `cargo test <name1> <name2>` (подстрочное совпадение) |
