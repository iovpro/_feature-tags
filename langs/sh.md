# Shell · `active`

| Поле            | Значение |
| --------------- | -------- |
| Файлы           | `--include=*.sh`, скрипты без расширения с shebang — перечислить явно |
| Комментарий     | `#` |
| Тег-группа      | Отдельная `#`-группа перед описывающими комментариями и `name() {`, отделённая от них одной пустой строкой; для скрипта без функций — перед первой командой основного сценария, **не** в шапке файла |
| Объявления      | Функция; основной сценарий скрипта |
| Ветка           | Хвостовой `# #f:…` на строке `pattern)` в `case` |
| Тесты           | bats: `*.bats`, тест — `^@test "(.+)"`, отдельная тег-группа перед `@test`, отделённая пустой строкой |
| Точечный прогон | `bats -f '<regex по именам>' tests/` |
